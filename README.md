# InfiniTG

InfiniTG is a cloud storage platform built with Laravel that uses Telegram as the storage backend.

## Features

- User Authentication
- File Upload & Download
- Gallery
- Favorites
- Trash
- Search
- Storage Dashboard
- Settings

## Tech Stack

- Laravel 12
- PHP 8.3
- MySQL
- Tailwind CSS
- Telegram Bot API (Upcoming)

## Roadmap

- ✅ Local Storage
- 🔄 Telegram Storage Integration
- ⏳ Share Links
- ⏳ File Preview
- ⏳ Admin Panel
